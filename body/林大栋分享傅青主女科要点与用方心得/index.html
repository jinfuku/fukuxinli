林大栋分享傅青主女科要点与用方心得

[身] 2026-03-16
📝 内容简介
本节课林大栋老师讲述了傅青主女科的要点以及用方心得，涵盖带下、月经、血崩、种子、妊娠、小产、难产、产后、养胎等妇科核心内容。课程深入解析了傅青主"辨证难于用方"的核心思想，以及妇科在气、血与肝脾肾三大脏腑之间平衡的整体观。
#傅青主女科 #中医妇科 #用方心得 #林大栋 #调经 #脏腑气血

核心理念

✨ 不难于用方，难于辨证

✨ 妇科在于气、血在肝、脾、肾三大脏腑之间的平衡

✨ 六味地黄丸，有补有泻，新陈代谢。地黄补肾、山药补脾、山茱萸补肝；泽泻泻肾、茯苓泻脾、牡丹皮泻肝

✨ 寻根溯源，洞察脏腑气血虚实转化，治其本，标病自除。

带下

带本身是生理的，但量太多、有味道、造成身体不适，就是带下了。带下的根本在于气陷（脾胃）。

🌸 五色带下方证对应

白带 → 完带汤
脾虚湿盛，脾虚肝郁 → 健胃而补脾
赤带 → 清肝止淋汤
肝火内炽，脾伤及肝，肝血不藏血
青带 → 加减逍遥散
肝经湿热，肝气逆 → 疏肝
黄带 → 易黄汤
任脉湿热，湿热相合 → 补土以化湿
黑带 → 利火汤
胃、命门、三焦、膀胱火旺 → 泄火湿自除

💡 临证提示：遇到带下都可以先用完带汤，如果没有效果，再看赤、青、黄、黑分型辨治。

调经

经水生于肾，源于肾中天葵的至阴之精。

🌸 月经异常方证对应

先期 → 两地汤、清经汤
肾水亏虚，无法抑制肝火
后期 → 温经摄血汤
血寒或气血不足
不定期 → 定经汤
肝气郁结，气机不畅，疏肝解郁
绝经过早 → 益经汤
肾精不足，天癸早竭
月经数月一行 → 助仙丹
气血两虚，经水稀少
绝经后复行 → 安老汤
冲任不固，年老经复
经前腹痛（少腹为甚）→ 宣郁通经汤
气滞血瘀，经前痛甚
经前脐下刺痛、所下如黑豆子、不孕 → 温脐化湿通
寒湿凝滞胞宫
经期混乱量时不定、色淡有块、乳房胀痛 → 加味四物汤
肝郁气滞，气血不调

血崩

血崩的本质是气脱，无法固摄血液。治疗原则：补气生血的同时，再加一点止血（炭类药）。

🌸 血崩方证对应

血持续漏失 → 重用人参黄芪
气虚不固，长期漏血
血崩昏迷 → 固本止崩汤
气随血脱，神志不清
老年血崩 → 加减当归补血汤
年老气血两虚，冲任不固
少妇血崩 → 固气散
气虚不摄，年少冲任未固
交感出血 → 引精止血汤
房事损伤，精血外泄
郁结血崩 → 平肝开郁止血汤
肝郁化火，迫血妄行
闪跌血崩 → 逐瘀止血汤
跌仆损伤，瘀血内停
血海太热 → 血崩清海丸
热入血海，迫血妄行

种子（不孕）

🌸 不孕类型与方药

瘦怯不孕：阴虚火旺，需大补肾水

肥胖不孕：脾虚湿盛，痰湿阻塞子宫，需提升脾气，化痰除湿

嫉妒不孕：怀抱素恶，嫉妒愤怒导致的肝气郁结

下部冰冷不受孕 → 温胞饮 / 温饱饮
肾阳虚衰，胞宫寒冷
肥胖不孕 → 加味补中益气汤
脾虚湿盛，升清降浊
身瘦不孕 → 养精种玉汤
肾精不足，冲任亏虚
骨蒸夜热不受孕 → 清骨滋肾汤
阴虚内热，虚火扰胞
腰酸腹胀不受孕 → 升带汤
带脉下陷，气机不畅
便涩腹胀足浮肿不受孕 → 化水种子汤
水湿停聚，气滞血瘀
胸满不思食不孕 → 并提汤
脾胃气滞，升降失常
胸满少食不受孕 → 温图毓麟汤
脾胃虚寒，中阳不振
少腹急迫不受孕 → 宽带汤
带脉拘急，胞宫受压

妊娠

⚠️ 关键要点：前3个月不要轻易行气，补气要到最后3个月

🌸 妊娠问题方证对应

恶阻 / 孕吐 → 顺肝益气汤
肾水全力孕育胎儿，无暇滋润肝脏，肝血太燥，需平肝补血，兼健脾开胃生阳
浮肿 → 加减补中益气汤
脾肺气虚，需大补脾血与肺气

小产

胎成于气，亦摄于气，小产的根本在于气血失守。气旺则胎牢，气虚则胎堕。

🌸 小产类型方证对应

气虚小产 → 救损安胎汤
气虚不能摄胎，气旺则胎牢
大怒小产 → 引气归血汤
需平肝中之火，引气归血
行房小产 → 固气填精汤
精大泄则肾水涸，气脱血崩，必须大补气与精
跌闪小产 → 理气散瘀汤
需大补气血佐以行瘀

难产

气血两虚，气所以开交骨，血所以转儿身。

🌸 难产处理要点

  • 可用至阴穴转胎儿
  • 交骨不开：不要用催生药，可以用降子汤
  • 横生倒产：针刺婴儿手足，然后母体服用转天汤，辅以升麻、牛膝助胎儿自动转身
  • 胞衣不下：不可强力拉扯，可大补气血——送胞汤
  • 气逆难产：需舒气兼补气

产后

🌸 产后调护方证对应

恶寒身颤 → 十全大补汤
气血两虚，正虚邪侵。寒由内生，颤由气虚
产后血晕 → 补气解晕汤 / 刺眉心法
气虚欲脱，心无血养，需大补气虚
乳汁不下 → 通乳丹
无气则乳无以化，必须大补气血，气血充盈，乳汁自下

💡 民间验方：乳汁不下，可用葱头刺激乳头乳房下乳

养胎

🌸 各阶段养胎方药

第1～3月（妇人平脉，阴脉小弱，渴不能食）→ 桂枝汤
调和营卫，安胎养正
第3～5月（补妈妈）→ 当归散
养血安胎，补益母体
第6月后（补胎儿）→ 白术散
健脾益气，充养胎元

妇科心法

✨ 妇科的疑难症，多和瘀血有关，可以查看小腿是否有肌肤甲错，以及口渴不欲饮等体征

✨ 气郁气滞：香附

✨ 血瘀积聚：益母草
